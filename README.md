

\# MIT 8103 - Advanced Database Systems



\## Academic Session

\## Project Title

University Student Result Management System



\## Case Study

Academic Excellence University (AEU)



\## Project Description

This project involves the design and implementation of a University Student Result Management System.



The system manages:

\- Student records

\- Academic departments

\- Lecturers

\- Courses

\- Semester registrations

\- Examination scores

\- Student grades and GPA



\## Technologies

\- PostgreSQL

\- MongoDB

\- SQL

\- Git and GitHub



\## Portfolio Activities

1\. Database Design and Modelling

2\. Query Processing and Optimization

3\. Transactions and Concurrency

4\. NoSQL and Advanced Data Models

5\. Distributed and Cloud Database Exercise
