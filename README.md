\# MIT 8103 - Advanced Database Systems



\## Academic Session

2026/2027



\## Project Title

University Student Result Management System



\## Case Study

Academic Excellence University (AEU)



\## Project Description

This project involves the design and implementation of a University Student Result Management System.



The system manages:

\- Student records

\- Academic departments

\- Lecturers

\- Courses

\- Semester registrations

\- Examination scores

\- Student grades and GPA



\## Technologies

\- PostgreSQL

\- MongoDB

\- SQL

\- Git and GitHub



\## Portfolio Activities

1\. Database Design and Modelling

2\. Query Processing and Optimization

3\. Transactions and Concurrency

4\. NoSQL and Advanced Data Models

5\. Distributed and Cloud Database Exercise



\## Project Status



\*\*All five practical portfolio activities have been completed and uploaded to this repository.\*\*



\### Completed Activities



1\. \*\*Database Design and Modelling:\*\* Designed and implemented the AEU relational database using PostgreSQL, including an ER diagram, relational schema, keys, constraints and normalisation.

2\. \*\*Query Processing and Optimisation:\*\* Implemented SQL queries, examined execution plans using `EXPLAIN ANALYZE`, created indexes and documented performance observations.

3\. \*\*Transactions and Concurrency:\*\* Tested transaction commits, rollbacks, isolation levels and concurrent database operations using PostgreSQL.

4\. \*\*NoSQL and Advanced Data Models:\*\* Implemented a MongoDB student-record collection and tested Create, Read, Update and Delete operations.

5\. \*\*Distributed and Cloud Databases:\*\* Implemented PostgreSQL table partitioning and documented proposed replication, sharding, high-availability and cloud deployment architectures.



\### Implementation Note



PostgreSQL partitioning and MongoDB CRUD operations were implemented and tested locally. Replication, multi-server sharding and cloud deployment are presented as proposed architectural designs and were not deployed as live services.
